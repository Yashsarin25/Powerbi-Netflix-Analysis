# Netflix Data Analysis Dashboard — Power BI

## Project Overview
This project uses Microsoft Power BI to analyze Netflix content and explore patterns in titles and ratings through data visualization.

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Exploratory Data Analysis

## Project Objectives
- Analyze Netflix titles and their ratings.
- Identify highly rated shows.
- Explore patterns in the available Netflix dataset.
- Present findings through an interactive Power BI dashboard.

## Dashboard
The Power BI report is available in the `.pbix` file included in this repository. Download the file and open it using Power BI Desktop to explore the report.
